How expansion works

  • Tags expand first, recursively, so a tag can contain other tags.
  • With dynamic_prompts on, each {a|b|c} picks one option — nested braces and {|shiny} optional words included — so choices stored inside tags work too.
  • seed drives the picks (fixed by default; randomize for a new pick each run). Braces without | are left untouched.
  • Output is tidied: doubled spaces, empty comma slots and trailing commas removed.

Editing tools

  • Save Tag asks for a name; on collision it shows old vs new side by side before overwriting.
  • Insert Tag or typing @ opens a searchable picker at the cursor.
  • Manage Tags: resizable dialog with search (names + text, highlighted), prefix groups (style_…), sorting, rename/delete with Undo, and diff-only saves so concurrent edits survive. Keys: ↑↓, Del, Ctrl+N, Ctrl+S.
  • Unknown refs render red and are counted in the title bar.

Prompt Pad

Scratchpad that saves and loads .txt files from SavedPrompts/. A connected text_in overrides the output.

System Prompt

Same idea for LLM system prompts: its own library, an Add folder… picker for outside libraries, .txt/.md loading.

Prompt Expander

Expands a short prompt through a local Ollama model (127.0.0.1:11434). Eight presets incl. a System prompt creator; Save/Delete Preset, Pick Model, max_tokens, keep_alive 0 to free VRAM.

Get Lines ≤32 outputs

Grows one output per line. In Auto the count follows the feeding text widget as you type, or the real count after a run. Connected outputs are never removed. Right-click → Lines to pin a fixed count.

Prompt Combiner

Joins parts in order between prefix and suffix. tidy cleans each part into a sentence; weighted (x:1.2) parts are left alone.

Combine Text ≤32 inputs

Joins any number of text inputs with a chosen delimiter; slots auto-grow.

Text

Plain multiline box with {a|b|c} dynamic prompts on by default.

Random Line Select

Splits text into lines and outputs one chosen by seed, wrapping to the line count.

Show Text

Live read-only preview, passes the text through. Runs standalone.

Load Prompts From File

Upload .txt, choose a separator (blank line, newline, ---, <>) and every prompt goes out as a list, so downstream runs once per prompt in one queue. start/limit pick a range; count is output.

Load Image Crop

Crop directly on the node preview: drag to draw, drag inside to move, corners to resize, double-click to clear. No crop = full image. aspect locks to presets; max_megapixels scales the result (0 keeps crop size), then both sides snap to resolution_steps using upscale_method.

Load Image

Pick or upload, preview, optional megapixel-target resize. 📋 Paste from clipboard saves the last copied image into input/ and selects it.

Load Images from Folder

Loads every image, or only clicked tiles. list keeps sizes and runs downstream once per image; crop, pad (with pad_color) and stretch normalise to the largest image as one batch.

Load Image Mini

Compact custom face: toolbar (upload/paste/⚙), arrow + thumbnail picker, preview and input/output size cards. The full resize engine — max MP, longest side, scale, fit, crop to fill, match ratio, snap, resample, accent — sits behind the gear. Outputs image + image_info.

Pad Image

Pads for outpainting and outputs outpaint_mask (feathered). Modes: manual dialog, target size, aspect ratio with anchor. Fill with colour, replicate, reflect or blurred edges; transparent padding; seam_blend.

Rotate Image

90 / 180 / 270 as radio-style toggles; clockwise flips direction.

Film Grain

Presets: Fine 35mm, Portra 400, Tri-X 400, 16mm, Super 8, or Custom sliders (intensity, size, colour, luminance response). Per-frame grain, seeded.

Image To SVG

vtracer vectorising with Accurate, Poster, Logo, B&W or Custom presets. Outputs SVG strings plus a re-rendered image to compare; optional save. Needs vtracer, resvg-py.

Compress Image

jpg / webp / png by quality, target KB (quality steps down until it fits), max dimension or lossless webp. Mask → alpha; jpg flattens on white.

Save Image

  • png / jpg / webp / avif to the output folder or any typed path; images pass through.
  • preset: lossless, visually_lossless, balanced, small — or custom quality widgets.
  • Changing format or preset re-encodes the last run live; a badge shows size and saving vs png.
  • Node keeps the image's proportions as you resize; new shapes snap the node.
  • preview mode skips writing; a cached copy survives restarts.
  • compare_image adds a before/after slider; click steps through a batch.

SaveMP4

h264 mp4 from an image batch with optional muxed audio. Encode preset, trim_to_audio, preview_only, and a clean in-node player.

Load Video

Outputs frames, audio, fps, seconds, VIDEO and info. start_frame, frame_cap and force_fps — only the selected stretch is decoded, audio trimmed to match.

Resolution

Aspect dropdown, preset buttons (multiples of 64, up to 4 MP), orientation buttons that mirror the ratio, batch stepper and a to-scale preview. Outputs width, height, empty latent, batch size.

Upscale Latent

Multiplier button grid (editable via right-click → MB Settings) or Custom…; method as a button row. Readout shows input → output latent and pixel size.

Slider

One slider whose output adopts the type, step and range of the input it connects to. ⚙ Slider Settings for min/max/step.

LoRA Stack

Any number of LoRAs on MODEL (and CLIP if connected). Drag to reorder, pill toggles, strength scrub with fill bar. ⓘ lists trigger words from sidecars, the safetensors header, or civitai by SHA256 (cached); tick to output them.

Load Models Combo

Diffusion model + CLIP + VAE in one node. Grouped menus: ★ favourites, 🕒 last 5, Search all…, subfolders. Presets save the whole set; missing files outlined red.

Sampler

KSampler with live preview and an optional hires second pass: upscale_by, denoise_2, steps_2, seed_2. Outputs latent and latent_pass1.

WiFi Send / Receive

Up to 20 named lanes under a channel. Receivers pick any channel in the workflow, including subgraphs, and mirror types, colours and names live. Same-channel nodes share a title colour; right-click → Go to sender/receiver. Duplicate channels or "no signal" block the queue with a clear message.

Route 66

Multi-lane reroute (≤20). Lanes appear as you wire, sockets take the type colour, double-click to name. Right-click → Tidy lanes, Compact.

Control Panel

Up to 16 blank controls that adopt the shape of whatever they're wired to — slider, toggle, filtered dropdown, seed with reroll, or text — and revert on disconnect.

Branch Runner

Queues only this node and its upstream (partial execution). Hover outlines the branch; runs 1–100; Alt+Enter runs selected runners.

Replace Node…

Right-click → swap a node in place. Links reconnect by name, index, then type; matching widgets, title, colour and mode carry over. One Ctrl+Z undoes it.

MB sidebar

Box icon in the left sidebar listing only this pack's nodes by category, with search. Drag to place, click to add at centre.

Accent: Pink (default), Green, Purple, Teal, Gold, Blue, Red, Orange, Indigo, Slate, Orchid or Custom. Optional accent-tinted UI and style polish.

Palettes

Node count badge, restart button, palette switcher, Replace Node menu, clipboard paste, notify-on-finish (custom mp3s). Node defaults for new nodes.
